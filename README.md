# Matt's Notebook

A personal notes vault for ideas, reference material, and ongoing projects. Notes are written in Markdown and organized for use with [Obsidian](https://obsidian.md/).

## Getting started

Open this repository as a vault in Obsidian, or read and edit the Markdown files with any text editor.

## Contents

- [Welcome](Welcome.md) — starting note for the vault
- **House Stuff** — home and making projects:
  - [3D Printing Projects](House%20Stuff/3D%20Printing%20Projects.md)
  - [Woodworking Projects](House%20Stuff/Woodworking%20Projects%20List.md)

Add notes as Markdown files and link between them with Obsidian-style links, such as `[[Note Name]]`.
